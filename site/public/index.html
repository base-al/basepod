// why basepod

What you get in one binary

Rootless Podman

No privileged daemon. Containers run under your own user and are supervised outside the control plane, so they survive restarts.

Caddy at the edge

Automatic HTTPS via ACME, on-demand TLS for custom domains, and zero-downtime config swaps through Caddy's admin API.

Single Go binary

One binary with SQLite embedded. Install it on any Linux VPS or a Mac — no external database, no sidecar services.

Web dashboard

A Vue 3 SPA embedded in the same binary: apps, a new-app wizard, deployment history — nothing extra to host.

Encrypted env vars

Secrets are encrypted at rest and injected into containers at deploy time. Once set, they're write-only.

Custom domains

Point a domain at an app and BasePod wires up routing and a certificate automatically — no manual Caddy edits.

Live log streaming

Watch container logs in real time from the dashboard or over SSE, without shelling in.

Open source

Apache-2.0, developed in the open on GitHub. Read the code, file an issue, send a PR.

// quickstart

Bare VPS to running app

The real commands — copied straight from the README. Swap the release asset for your platform.

  1. 1

    Download & install

    curl -LO https://github.com/base-al/basepod/releases/download/v0.2.0/basepod_v0.2.0_linux_amd64.tar.gz
tar xzf basepod_v0.2.0_linux_amd64.tar.gz
chmod +x basepod

    macOS: use basepod_v0.2.0_darwin_arm64.tar.gz (Apple Silicon) or _darwin_amd64 (Intel). All four platform archives and checksums.txt are on the releases page.

  2. 2

    First-run setup

    ./basepod setup \
  --config ~/.config/basepod/config.yaml \
  --data-dir ~/.local/share/basepod \
  --root-domain apps.example.com \
  --admin-email admin@example.com \
  --admin-password change-me-please
  3. 3

    Run the control plane

    ./basepod server --config ~/.config/basepod/config.yaml

    The API listens on 127.0.0.1:3080; BasePod's own Caddy serves apps on 80/443.

  4. 4

    Deploy — dashboard or API

    Open http://localhost:3080, sign in, and create an app from an image — or drive it with curl:

    TOKEN=$(curl -s localhost:3080/api/v1/auth/login \
  -d '{"email":"admin@example.com","password":"change-me-please"}' | jq -r .token)

curl -s -H "Authorization: Bearer $TOKEN" localhost:3080/api/v1/apps \
  -d '{"name":"hello","image":"docker.io/traefik/whoami:latest","port":80}'

curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  localhost:3080/api/v1/apps/hello/deploy
