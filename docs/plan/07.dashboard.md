## Stack

- **Vue 3 + TypeScript + Vite**, `web/` directory.
- **Nuxt UI v4** as the component library (it supports plain Vue apps via
  its Vite module — no Nuxt framework needed; the PrimeVue fallback
  discussed below was never needed in practice — see `web/package.json`).
- Pinia for state, Vue Router, TanStack Query (vue-query) for API
  caching/refetching.
- Charts: lightweight (uPlot or chart.js) for CPU/mem sparklines —
  not yet built (see deferred list above).
- Build output embedded into the Go binary via `go:embed` of `web/dist`;
  the daemon serves it with SPA fallback. Setting the `BASEPOD_DEV_UI`
  environment variable to a local Vite dev server URL makes the daemon
  reverse-proxy the dashboard to it instead, for hot reload during
  development (see `internal/server/server.go`'s `dashboardHandler`) —
  there is no `basepod server --dev` flag.

No separate frontend deployment, no Node.js on servers — Node is a
build-time dependency only (CI builds `web/dist` before `go build`).

## Design intent

Dense-but-calm ops dashboard: sidebar navigation (Apps, Templates,
Team, Servers, Plugins, Settings), top bar with team switcher + user
menu. Dark mode from day one (Nuxt UI supports it natively). Live data
everywhere it matters — status changes arrive over the `/events` SSE
stream, no manual refresh.

## Frontend architecture notes

- **Reality (v0.3):** a hand-written, hand-kept typed API client
  (`web/src/lib/api.ts`) — a thin typed `fetch` wrapper with the request
  methods the dashboard actually calls, no codegen, no generic CRUD
  abstraction. No OpenAPI spec exists yet in this repo, so there is
  nothing to generate from or drift-check against; that remains future
  work (see doc 11's documentation plan).
- SSE wrapper composable (`useEventStream`) with auto-reconnect/backoff
  shared by logs, build logs, stats, events.
- Route-level code splitting; the whole dashboard should stay light —
  budget: < 500 KB gzipped initial load.
- All state changes optimistic-with-rollback only where safe (env editor
  no, restart button yes).
- i18n scaffolding (vue-i18n) from the start, English-only content in v1.

## Testing

- Vitest component tests for critical logic (env editor parsing, SSE
  composable, RBAC-conditional rendering).
- One Playwright smoke flow in CI against a real dev server: login →
  create app from image → see it running → view logs (doc 11).
