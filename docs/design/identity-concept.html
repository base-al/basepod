identity concept

A direction to react to before the full reskin lands — built on your existing wordmark, with a palette and console layout derived from it. Nothing here is shipped yet.

01 — the ground

Copper on graphite, not another green terminal

Every self-hosting tool reaches for the same neon-green-on-black. Copper is metal: hardware you own, sitting in a rack you chose. The neutrals carry a warm bias so the ground reads as considered rather than default grey, and the status colours stay clear of the accent so a warning never competes with a button.

02 — the mark

The wordmark you already had, and a b cut from it

The wordmark stays exactly as drawn — geometric, lowercase, unfussy, one path that inherits colour, so it can tint amber when a deploy is running or red when Podman is unreachable. The small mark is lifted from its own letterforms rather than invented, so the favicon and the header are visibly the same family.

03 — the voice of the type

Monospace leads, prose follows

Slugs, image refs, hostnames and numbers are all things you copy, compare and type back. They get monospace with tabular figures so columns line up and a stray character is visible. Headings borrow the same face so the interface sounds like the tool it is; running prose stays in the system sans, which is what people actually read comfortably.
